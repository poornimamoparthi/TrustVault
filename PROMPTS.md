# TrustVault - AI Prompts and Development Notes

This document records the prompts and development guidance used while building TrustVault.

## Prompt 1: Project Planning
"Help me build a secure confidential-document management web application named TrustVault. Use React for the frontend, Flask for the backend, and SQLite for local development."

## Prompt 2: Authentication
"Implement user registration and login with secure password hashing and appropriate validation."

## Prompt 3: Role-Based Access Control
"Implement role-based access for Admin, Document Owner, and Viewer. Restrict document actions according to the user's permissions."

## Prompt 4: Document Management
"Implement document upload, storage, and download functionality. Ensure that users can access only documents they are permitted to access."

## Prompt 5: Password Recovery
"Implement email-based password recovery using expiring reset tokens. Validate reset requests securely and allow users to set a new password."

## Prompt 6: Security and Testing
"Review the application for common security issues, validate inputs, protect sensitive configuration, and test the main authentication and document-management workflows."

## Prompt 7: Documentation and Deployment
"Prepare project documentation, explain how to run the frontend and backend locally, and identify the configuration changes required for production deployment."

## Development Note
These prompts document the development goals and guidance for the project. The implementation should be tested before deployment, and all credentials, API keys, and environment files must remain private.
